May 14, 2026

1.8

It's time for Minecraft Oldschool Edition 1.8, our biggest most expansive update yet!

Features (Client):
+ Sky Dimension has been fully overhauled! It now includes a new skybox, refreshed aesthetics, expanded terrain generation (including missing biomes and trees from normal terrain), and mob dungeons. Sky is now a truly playable map option.
+ Added an Infdev world generator option.
+ Added a Vulkan renderer option (OpenGL remains the default renderer).
+ In Vulkan mode, added backface culling and GPU-driven mesh rendering through the Mesh Mode setting in Video Settings.
+ Added FSR 3.1 upscaling support in Vulkan mode! (Great for Steam Deck!)
+ Added mipmap texture filtering support.
+ Added VRR (Adaptive Sync) support for compatible monitors.
+ Added a Lazy Chunk Loader option so chunks keep loading around you while standing still (similar to OptiFine).
+ Added an isometric screenshot mode on F4 / Down On D-Pad, with matching keyboard/mouse and controller layouts.
+ Added an Indev Title Screen mode.
+ Added a Zoom key (default: C).
+ Added a cloud height slider from default world heights up to Y=256.
+ Added an in-game FPS counter.
+ Moved the Language option to the title screen.
+ Added a Colorblind Filter in Accessibility Settings.
+ Added skin customization options so players can enable or disable visible skin layers like modern Minecraft.
+ The "Press {Button} to open your inventory" achievement popup now displays the correctly assigned inventory button icon when using a controller.
+ Quick Move in inventory menus now plays the Console Edition-like gliding animation when moving the item.

Gameplay Changes:
+ Updated armor balance while keeping durability unchanged. Damage reduction now scales by armor tier:

TierArmorDamage Reduction
Leather7~28%
Gold11~44%
Chain12~48%
Iron15~60%
Diamond20~80%

+ Added functional Sponges that absorb water and become Wet Sponge after one use; dry them in a furnace to reuse them.
+ Added Redstone Blocks (crafted from 9 redstone) that provide constant power like redstone torches and can be pushed by pistons.
+ Added Coal Blocks (crafted from 9 coal); one Coal Block burns for 9x as long as one coal item.
+ Chests can now be placed facing any direction thanks to under-the-hood engine changes.
+ Clocks can now be placed on walls and output a redstone signal whose strength depends on time of day.
+ Added Beta 1.8-style bow stances as a visual-only option (toggleable in Eye Candy settings).
+ Alpha and Indev worlds now use more era-accurate textures for select blocks (including era-specific wool, metal blocks, and brick textures).

Features (Server):
+ Multiplayer players and entities now move much smoother.
+ Voice chat reliability has been significantly improved. Voice now uses a dedicated UDP port with TCP fallback (default voice port: 24454).
+ Proximity voice chat is now positional (3D directional audio based on speaking player location).
+ Transitioned engine compression from Zlib to Zstd.
+ Introduced WAL logs based on Scaevolus' recommendation.
+ Introduced McRegion 2, the successor to Scaevolus' McRegion format.
+ Added better Alpha/McRegion conversion than vanilla for improved legacy world migration.
+ Added Scaevolus to the Credits menu for their work on the original McRegion format.

Mar 10, 2026

1.7.7

A translation and stability update!

Fixes (Translations & Localization):
* Fixed item tooltips not displaying translated names when hovering over items in the creative menu. The translation system now correctly prioritizes modern JSON language files over legacy formats.
* Fixed Polish language file failing to parse, preventing Polish translations from loading.
* Fixed duplicate translation keys in the English language file that were causing parse errors.
* Fixed missing translations for various items and blocks across all supported languages.
* English is now always first in the language selection menu.
* Added cross-language font support – players using English can now see Japanese, Chinese, and Korean characters in chat messages, books, and signs written by other players.

Fixes (Gameplay):
* Fixed spontaneous camera movement when moving the mouse shortly after closing a menu or chat window.
* Fixed a crash when adjusting voice chat volume caused by a null pointer exception in the slider widget.
* Fixed beds dropping as items in Creative mode when breaking the top half.
* Fixed stone bricks recipe flickering and disappearing in multiplayer – the recipe was missing on the server.
* Fixed world type selector cycling through invalid types (0-31) instead of only valid world types.
* Fixed "tile.bed.sleep.disabled" appearing as raw text instead of "Sleeping is disabled" when beds are disabled on a server.

Fixes (Creative Menu):
* Fixed Wooden Slabs missing from the Creative menu.
* Fixed various dye items (Ink Sac, Rose Red, Cocoa Beans, Lapis Lazuli, Light Grey Dye, Bonemeal) not appearing or being incorrectly categorized.

Fixes (Achievements):
* Completely rebuilt the achievement system for both client and server to fix inconsistencies where achievements wouldn't unlock or display properly.
* Fixed "Taking Inventory" now properly unlocks when you open your inventory, not before.
* Fixed achievement prerequisites – achievements like "Getting Wood" now correctly require their parent achievement first.
* Fixed achievement broadcasts – all achievements (including "Taking Inventory") are now announced to other players when advertiseAchievements is enabled.

Notes:
* Language pack creators: Missing translations are now logged to the console with the expected JSON key and English text for easy reference.
* The translation system now uses a priority order: JSON translations → English fallback → legacy .lang files → synthesized names.

// The Oldschool Team

1.7.6

A comprehensive bug fix and performance update!

Features (Client):
+ Added performance profiler! Use /profile start, /profile stop, and /profile report to diagnose performance issues and help identify bottlenecks.
+ Creative search now uses localized names! Searching for "axes" or "netherrack" now works correctly using the language file translations.
+ Added voice chat settings including microphone volume slider, noise suppression, auto gain, voice activation detection, and a live input level meter.
+ Added Mic Test button now previews your microphone audio in real-time before joining voice chat.

Fixes (Client):
* Fixed ghost flames lingering on zombies and skeletons killed by sunlight. Fire effects are now properly cleared on death.
* Fixed ghost items remaining after player death. Stale entities are now cleaned up automatically.
* Fixed items visually dropping on death when keepInventory is enabled. Players now see their items stay in their inventory.

Performance (Client):
+ Added memory pool limits to prevent memory bloat from Vec3D and AxisAlignedBB object pools.
+ Optimized random block ticks and mob spawning for improved performance.
+ Added chunk unload tracking to the performance profiler for better memory analysis.

Features (Server):
+ Added performance profiler with /profile command for players and console.
+ Added Debug Commands section to the Server GUI with profiler controls (Start, Stop, View Report, Save Report, Status, Clear).
+ The advertiseAchievements gamerule now defaults to true – achievements are broadcast to all players by default.
+ Voice chat now uses a dedicated UDP port! Server admins must forward the voice chat port (default: game port 24454) in addition to the main server port for voice chat to work.

Fixes (Server):
* Fixed arrows depleting in Creative mode when using a bow. Creative players now have infinite arrows.
* Fixed books not saving title, author, or page contents after signing in multiplayer.
* Fixed unsigned Book and Quill contents not persisting in multiplayer.
* Fixed server ping flickering between "Communication error" and normal MOTD when refreshing the server list.
* Fixed "End of stream" errors when pinging saved servers – improved connection reliability.
* Fixed voice chat info messages being word-wrapped and leaking fragments into chat.
* Fixed chat not working after switching from Hardcore to Survival. Players who were in hardcore mode are now properly reset when the server changes game mode.
* Fixed keepInventory not preventing item drops on death. Items no longer drop as entities when the gamerule is enabled.
* Fixed achievements not announcing in chat (e.g., "Taking Inventory"). Added fallback achievement name translations.
* Fixed missing translations for several achievements including "DIAMONDS!", "We Need to Go Deeper", "Librarian", and more.

Performance (Server):
+ Added memory leak prevention with pool size limits for Vec3D and AxisAlignedBB objects.

Feb 01, 2026

1.7.4

A major compatibility and bug fix update!

Features (Server):
+ Added /gamerule keepInventory – set to true to prevent players from dropping items on death (defaults to false).
+ The keepInventory gamerule is now available in tab-completion.

Fixes (macOS & LWJGL3):
* macOS is now fully supported! The game runs natively on Apple Silicon and Intel Macs using LWJGL3.
* Fixed black screen issues on macOS by properly handling AWT/GLFW conflicts.
* Fixed font rendering and texture loading on macOS using STB image loading fallbacks.
* The launcher now automatically installs required macOS compatibility patches.

Fixes (Lighting & Rendering):
* Fixed light sources not lighting up the environment when chunk priority is set to "Fast Chunks". The lighting engine now dynamically adjusts processing rates to prevent dark patches.
* Added fallback to synchronous lighting when the async queue is overloaded, ensuring lighting updates are never dropped.

Fixes (Resource Packs):
* Fixed custom resource packs breaking all sounds. The sound engine now only replaces sounds that exist in the resource pack, keeping defaults for everything else.
* Fixed resource pack textures not loading when pack contents are in a subfolder. The game now auto-detects nested folder structures.
* Fixed pack.png thumbnails not displaying in the resource pack menu.
* Fixed pack descriptions not loading from pack.mcmeta files.

Fixes (Input & Controls):
* Fixed inconsistent mouse/camera smoothness by ensuring VSync properly syncs with display refresh rate.
* Fixed keyboard input not working in text fields (server address, chat, etc.) due to GLFW key/character event handling.
* Added proper Cmd+C/V/X/A support on macOS for copy, paste, cut, and select all operations.

Fixes (Server):
* Fixed unbanned hardcore players being unable to respawn. After an admin unbans a hardcore player, they can now rejoin and click Respawn to continue playing.
* Fixed hardcore players switching to Survival mode after being unbanned and respawning. Players now correctly stay in Hardcore mode.
* Fixed unbanned hardcore players logging in dead. Health and death state are now reset on login for unbanned players.
* Fixed "Delete World" appearing in multiplayer hardcore instead of the proper death screen.

Fixes (Client):
* Fixed the Credits screen displaying garbled text. Multi-line credits are now properly centered and wrapped to fit the screen.
* Removed excessive debug logging that was spamming the console.

Fixes (Launcher):
+ The launcher now automatically downloads and installs the net.minecraft.json compatibility patch for macOS users.

Credits Update:
* Updated in-game credits with proper attributions for Mojang Studios, C418, PhuWorks (Mojangles-v2 font), and EricWaffles.

// The Oldschool Team
